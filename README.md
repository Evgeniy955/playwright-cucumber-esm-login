# Setup

## Terminal commands

1. Check Node.js version:
   ```bash
   node -v
2. Install Node.js version 20:
    ```bash
    nvm install 20
    nvm use 20
    ```
3. Check npm version:
   ```bash
   npm -v
4. Update npm to the latest version:
   ```bash
    npm install -g npm
5. Install dependencies:
   ```bash
    npm install
   
6. Install dotenv:
   ```bash
    npm install dotenv
